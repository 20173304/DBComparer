# DBComparer

같은 MSSQL 서버의 서로 다른 DB에서 테이블 데이터를 비교하는 Windows Forms 프로그램입니다. .NET Framework 4.7.2가 필요합니다.

## 실행

Visual Studio에서 `DBComparer.sln`을 열어 빌드하거나 `DBComparer/bin/Release/DBComparer.exe`를 실행합니다.

1. 서버 IP, `서버\인스턴스` 또는 `서버,포트`를 입력합니다.
2. Windows 인증 또는 SQL 계정/암호를 지정하고 **연결 확인**을 누릅니다. 연결에 성공하면 접근 가능한 DB 목록이 표시됩니다.
3. DB1과 DB2에 서로 다른 DB, 비교할 테이블을 선택합니다. 각 테이블의 검색창에 테이블명이나 스키마명의 일부를 입력하면 대소문자 구분 없이 목록을 좁힙니다. 검색창을 비우면 전체 목록으로 돌아오고 `검색 결과 / 전체 개수`를 표시합니다. 검색 결과에 기존 선택이 남아 있으면 선택과 비교 설정을 유지하며, 제외되면 테이블을 다시 선택해야 합니다. 각 DB의 테이블 목록을 가져오며 공통 이름의 컬럼을 표시합니다.
4. 비교할 컬럼을 체크하고 행을 고유하게 식별할 비교 키를 체크합니다. 복합 키도 가능합니다. 키는 체크한 비교 컬럼에 없어도 조회에 포함됩니다. 조회 결과에서 키가 중복되면 중단합니다.
5. 필요한 경우 양쪽 조회 조건을 각각 입력합니다. `WHERE`는 제외합니다. 예: `Status = 'Active' AND CreatedAt >= '2026-01-01'`. 비워 두면 전체 행이 대상입니다. 조건에 사용하는 컬럼은 비교 대상으로 체크하지 않아도 됩니다.
6. **데이터 비교**를 누릅니다. 일치/불일치와 행 수를 표시하고, 표에는 다른 셀과 한쪽에만 있는 행의 값을 표시합니다. 모두 일치하면 상세 표는 비어 있습니다.

## 비교 기준과 제한

- 행 순서와 무관하게 키로 대응합니다. 문자열은 대소문자와 공백을 구분하고 NULL은 빈 문자열과 다릅니다. 바이너리는 바이트 내용으로 비교합니다. 비교 및 키 컬럼의 .NET 자료형이 다르면 오류를 표시합니다.
- 기본 최대 조회량은 DB별 10,000행이며 조절할 수 있습니다. 한도보다 많은 행이 나오면 비교를 중단해 부분 조회에 의한 잘못된 일치 판정을 방지합니다. 모든 데이터를 메모리에 적재하므로 대용량은 조건으로 분할하세요.
- 양쪽 모두 0행이면 ‘양쪽 조회 결과 없음’으로 표시합니다.
- 조회 시점은 DB별로 다를 수 있습니다. 변경 중인 테이블의 정합성 검증은 변경을 멈추거나 동일 시점으로 복원된 DB에서 실행하세요.
- SQL 조건은 사용자가 입력하는 SQL 식입니다. 주석과 세미콜론은 거부하지만 SQL 보안 샌드박스는 아닙니다. **반드시 필요한 테이블의 SELECT 권한만 가진 읽기 전용 계정**으로 사용하세요. 연결 암호는 파일로 저장하지 않습니다.
- SQL Server에 접근할 네트워크, 로그인, DB 및 테이블 조회 권한이 필요합니다. 연결 시간 제한은 10초, 쿼리는 120초입니다. 사용자 정의 CLR 등 특수 자료형은 별도의 대응이 필요할 수 있습니다.

## 값 변환 규칙

테이블과 비교 컬럼을 선택한 후 **값 변환 규칙** 버튼에서 컬럼, DB1 값, DB2 기대 값을 등록하고 적용합니다. 예를 들어 `A / TEST / MIC`를 등록하면 A 컬럼의 DB1 값이 TEST일 때 DB2가 MIC여야 일치입니다. DB2에 TEST가 그대로 남아 있으면 불일치입니다. 원본 DB 데이터는 수정하지 않습니다.

여러 컬럼과 여러 값의 규칙을 등록할 수 있습니다. 문자열 전체를 대소문자와 공백까지 정확히 비교하며, 부분 치환이나 연쇄 변환은 하지 않습니다. 빈 입력은 빈 문자열이며 NULL 변환과 숫자/날짜 컬럼 변환은 지원하지 않습니다. 비교 키에는 변환을 적용하지 않으므로 변경되지 않은 식별 컬럼을 키로 선택하세요. 규칙 컬럼은 비교 대상으로 체크해야 합니다.

상태 표시줄에는 규칙으로 기대 값과 일치한 셀 수가 표시됩니다. 실패한 셀의 상세 결과에는 원본 값, 실제 값, 기대 값이 표시됩니다. 규칙은 프로그램 실행 중에만 유지되며 연결, DB, 테이블 변경 또는 컬럼 다시 불러오기를 실행하면 초기화됩니다.

## 검증

Release 빌드와 `tests/ComparisonTests.cs` 비교 엔진 테스트를 제공합니다. 실제 서버 연결/메타데이터/조회 조건은 실행 환경의 MSSQL 접속 정보로 확인해야 합니다.

## 코드 구성

- `MainForm.cs`: 이벤트 연결, DB 연결·조회, 비교 실행 및 결과 표시
- `MainForm.Layout.cs`: 화면 컨트롤, 영역별 배치, 스타일 적용
- `Database.cs`: MSSQL 연결 및 조회 쿼리
- `Comparison.cs`: 키 기반 비교, 변환 규칙 검증, 불일치 집계
- `TablePicker.cs`: 테이블 목록 검색과 선택 유지
- `ValueRulesForm.cs`: 값 변환 규칙 편집 창
- `BlueTheme.cs`: 공통 색상과 컨트롤 스타일
- `BufferedControls.cs`: 깜빡임을 줄이는 컨트롤 및 처리 중 입력 차단
- `.editorconfig`: C# 들여쓰기와 줄바꿈 규칙
